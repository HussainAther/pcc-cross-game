# Bundled frozen source summaries

This directory contains only small synthetic validation summaries copied from the named frozen source snapshots. It contains no human poker data.

- `pcc-poker-v0.8.0/`: immutable pre-human Poker validation summaries.
- `pcc-liars-dice-v0.4.0/`: frozen Liar's Dice balance, mechanism, and construct-recovery summaries.
- `pcc-rps-v0.2.0/`: frozen RPS negative-control and effective-Chaos falsification summaries.

`PROVENANCE.json` records SHA-256 hashes for every bundled JSON source.
